## frames template init

Write a frame.yaml scaffold from a template, ready to fill in and publish

```
frames template init [flags]
```

### Options

```
      --dir string        Directory to write frame.yaml into (default ".")
      --force             Overwrite an existing frame.yaml
  -h, --help              help for init
      --template string   Template id from frames template list
```

### Options inherited from parent commands

```
      --api-url string            Registry URL; overrides api_url config and FRAMES_API_URL
      --credentials-path string   Credentials file path (for testing)
```
